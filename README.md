# Forkify Recipe App Project

This is my implementation of the Forkify project from Jonas Schmedtmann's JavaScript course - a recipe search and bookmarking application built with modern JavaScript, HTML, and CSS.

## Features

- 🔍 Search over 1,000,000 recipes using the Forkify API
- 📖 View complete recipe instructions and ingredients
- ❤️ Bookmark your favorite recipes
- ✏️ Upload and save your own custom recipes
- ⚖️ Dynamically adjust ingredient quantities based on servings
- 📱 Fully responsive design

## How to Run Locally

1. Clone the repository:
```bash
git clone https://github.com/qhuy135520/forkify
```
2. Install dependencies:
```bash
npm install
```
3. Start the development server:
```bash
npm start
```
4. Open in browser:
```
http://localhost:1234
```

## API Used

This project uses the Forkify API (2.0) - a recipe API specifically created for this course project. Documentation: [Forkify API](http://forkify-api.jonas.io/)
